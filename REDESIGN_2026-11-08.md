# Executive Architectural Hospitality — site redesign

A senior art-direction pass over the live Workspace Junction experience. The
site is re-proportioned, re-layered and re-contrasted; **nothing it says
changed**.

## Preservation

- **Zero copy modification.** Every heading, paragraph, bullet, badge and
  button label is byte-for-byte what it was. The only text added anywhere is
  structural numbering already present in the data (`01`–`06` on use cases,
  `01`–`09` on the service index) and the hero slide folio.
- **Zero palette change.** The same forest, cream and amber brand colours,
  re-proportioned to the 60 / 30 / 10 luxury surface rule.
- **Zero commercial change.** Service names, tiers, prices ($50, $100, $150,
  $250, $350, $75 / $150 / $225 sessions), feature inclusions, testimonials,
  FAQs and contact details are untouched and still read from the catalogue.
- **No invented services, locations or metrics.**

## How it was built

The visual language lives in one new last-loaded stylesheet,
`app/architectural-redesign.css`, scoped to
`.wj-platform[data-art-direction="architectural"]`. The existing cascade is not
deleted or rewritten, so all 183 routes keep working. Where the site's own
`@layer wj-button-contract` and `@layer wj-consistency` legitimately own a
decision, the corrections are authored **inside those layers** rather than
fighting them with escalating `!important`.

## Audit fixes

| Diagnosis | Fix |
| :--- | :--- |
| Three photographs repeated across six persona cards | Each card now has its own photograph. `withDistinctImagery()` in `lib/use-cases.ts` keeps the first use of any image and gives repeats their own, so an administrator can still set any artwork without reintroducing a duplicate. |
| Overcrowded two-tier navigation | Glassmorphic sticky bar plus a precision category index with 16px line icons, sliding gold underline and compression on scroll. |
| Uniform white-box card grids | Asymmetric bento (4/2, 2/4, 3/3) for personas, 2×2 feature bento plus a 3×3 Swiss index table for the ecosystem, Swiss ledger for stats, 7:5 editorial splits for Events and Meeting Rooms. |
| Dark-on-dark CTAs disappearing | Secondary actions on dark surfaces are warm-ivory hairline ghost buttons, `1px solid rgba(253,251,247,.35)` on `#FDFBF7` text. |
| SEO-heavy headings reading as raw text | Controlled measure (22ch on location headings, 26ch elsewhere), balanced wrapping and a tightened editorial scale. |
| Intrusive auto-firing modal | The campaign popup is no longer a modal: no scroll lock, no focus steal, no overlay. It docks as a dismissible contextual card. |
